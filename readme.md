EGFR Inhibitor Potency and Structure-Activity Relationship Analysis

Introduction: This project explains the relationship between molecular properties, chemical structures, and experimentally reported inhibitory potency of compounds targeting EGFR. I developed this project as an independent learning exercise with a focus on experimental data analysis and molecular structure activity relationship. 

Objectives: Process experimental EGFR inhibitor activity data
Examine reported IC50 values and calculate pIC50
Retrieve molecular structures and calculate physiochemical descriptors
Explore relationship between molecular properties and inhibitory potency.

Data Source: 
Database: chEMBL
Target: Human EGFR
Target chEBL ID: CHEMBL203
Selected assay: CHEMBL674643
Publication DOI: https://doi.org/10.1021/jm00130a020
Tools: Python (Pandas, Numpy, Matplotlib, RDKit,
Requests, chEMBL API)

Conclusion: During the project a total of 44 compounds passed the activity data filtering criteria. HBA and TPSA showed moderate positive Pearson Correlation with pIC50 in the dataset. CHEMBL76589 was the most potent compound in the seected dataset with and IC50 of 125nM and a pIC50 of 6.90. The preliminary structural coparisons revealed recurring aromatic rings, phenolic hydrocyl groups and nitrile containing conjugated systems among several of the more potent compounds. 

Future Directions
Potential extensions include molecular fingerprint analysis, molecular similarity comparisons, larger datasets and more detailed structure-activity relationship investigations.
